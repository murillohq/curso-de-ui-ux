# 🎨 Curso de UI/UX

Repositório com os trabalhos práticos desenvolvidos durante o curso de **UI/UX**, aplicados a um estudo de caso fictício: o app de pedidos da **Pizza Company**.
---

## 📌 Sobre o projeto

Os exercícios simulam o processo de design de um produto real, cobrindo desde o wireframe inicial das telas até o mapeamento da jornada do usuário, aplicando conceitos de usabilidade, heurísticas de design e diretrizes de interface (Material Design).
---

## 📂 Estrutura do repositório

| Arquivo | Descrição |
|---|---|
| [`wireframeSiteDeVendas.html`](./wireframeSiteDeVendas.html) | Wireframe de baixa fidelidade do fluxo de compra: login/cadastro, tela inicial, detalhe do produto, carrinho e confirmação do pedido. Inclui comparativo "antes x depois" aplicando diretrizes do Material Design 3. |
| [`jornadaUsuario.html`](./jornadaUsuario.html) | Mapa da jornada do usuário no fluxo de compra, com as etapas, ações, sentimentos, pontos de frustração e oportunidades de melhoria identificados em cada uma. |

---

## 🚀 Como visualizar

Os arquivos são páginas HTML autocontidas (não precisam de instalação). Para ver localmente:

```bash
git clone https://github.com/murillohq/curso-de-ui-ux.git
cd curso-de-ui-ux
```

Depois, é só abrir o arquivo desejado direto no navegador:

```bash
open wireframeSiteDeVendas.html   # ou clique duas vezes no arquivo
open jornadaUsuario.html
```
